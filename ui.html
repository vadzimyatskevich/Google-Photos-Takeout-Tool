Restore Google Takeout photos

Files are read straight from the zip archives. Metadata from the JSON sidecars is written into the photos and videos. Source files are not modified.

1. Sources

Folders of takeout-*.zip archives, individual zip files, or folders that are already extracted — one path per line. Duplicates across exports are removed automatically.

2. Where to save

Album folders take no extra disk space (NTFS or same-filesystem hard links), and each photo is copied once. Free space needed is about the size of the photos.

3. Layout and options

Pause freezes the job in place; Stop ends it — Start again continues from saved progress.
