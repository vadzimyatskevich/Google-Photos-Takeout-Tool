TakeoutRestore — восстановление фото из Google Takeout
=======================================================

Программа берёт архивы Google Takeout (takeout-*.zip) прямо как есть, без распаковки,
раскладывает фото и видео по папкам ГОД\ГОД-МЕСЯЦ и записывает в сами файлы
дату съёмки, GPS-координаты, описание, людей и альбомы из JSON-файлов Google.
Исходные архивы и папки НЕ изменяются и НЕ удаляются.

КАК ПОЛЬЗОВАТЬСЯ
1. Распакуйте этот zip в любую папку (например, на рабочий стол).
2. Дважды щёлкните TakeoutRestore.exe — откроется окно программы (браузер и
   чёрная консоль не нужны).
   Windows SmartScreen может предупредить, что программа неизвестна (она не подписана):
   нажмите «Подробнее» -> «Выполнить в любом случае».
   При первом запуске программа распаковывает встроенный ExifTool (несколько секунд).
   На Windows 10/11 уже есть WebView2, который использует окно.
3. Шаг 1 «Источники»: добавьте папку, например D:\Google Photo Vadzim
   Можно добавить другие выгрузки Takeout: папки с zip, отдельные zip или
   распакованные папки. Одинаковые фото из разных выгрузок, альбомов и частично
   распакованных папок будут сохранены только один раз.
4. Шаг 2: папка назначения, например D:\Фото (восстановлено)
   (НЕ внутри папки с архивами.) Выберите структуру папок и режим альбомов.
5. Шаг 3: сначала «Пробный прогон» — ничего не записывается, но будет показано,
   сколько файлов, дубликатов, сколько места нужно; откройте отчёт.
6. Затем «Начать восстановление». Если прервать (или закрыть окно), повторный запуск
   с той же папкой назначения продолжит с места остановки и не создаст дублей.
   При необходимости старый веб-интерфейс: TakeoutRestore.exe -web.

ЧТО ПОЛУЧИТСЯ
  D:\Фото (восстановлено)\2021\2021-05\IMG_20210524_110114.jpg   — все фото по датам
  D:\Фото (восстановлено)\Альбомы\Germany 2017\...               — ваши альбомы
  D:\Фото (восстановлено)\Без даты\                              — файлы без даты
  D:\Фото (восстановлено)\_Корзина\                              — то, что было в корзине Google
  D:\Фото (восстановлено)\_restore\report.html                   — отчёт (+ files.csv, log.txt)

ПРО МЕСТО НА ДИСКЕ
Фото копируются один раз. Папки «Альбомы» сделаны жёсткими ссылками NTFS: это тот же
файл, он виден в двух местах, но место занимает один раз. Это работает, только если
папка назначения на диске NTFS (обычно C: и D: — NTFS). Если удалить файл в альбоме —
он останется в папке по годам, и наоборот. Если нужны настоящие копии — выберите
«Отдельные копии». Нужно свободного места примерно столько, сколько весят фото
(для ~45 ГБ архивов — около 45 ГБ); программа проверит это перед началом.

ДАТЫ И ЧАСОВОЙ ПОЯС
Google хранит время в UTC; программа переводит его в часовой пояс этого компьютера
(можно указать другой, например Europe/Minsk). Уже имеющиеся в файле дата/GPS не
перезаписываются (если не включить соответствующую галочку). Для AVI/BMP рядом
создаётся файл .xmp с метаданными. У всех файлов дата изменения/создания = дата съёмки.

ЯЗЫК
По умолчанию интерфейс и названия папок английские: Albums, No date, _Trash,
Archive, Unknown month. Переключатель EN / RU — вверху страницы, выбор
запоминается. В командной строке: -lang en|ru|de|fr|es|pl|lt (справка на русском:
TakeoutRestore.exe -lang ru -h).
Для уже созданной папки назначения имена папок не меняются при смене языка:
язык папок записан в _restore/state.json, чтобы библиотека не разъехалась на
две схемы. Сообщения и отчёт идут на языке текущего запуска.
С -lang ru (или выбором «Русский» в списке) папки называются так, как в разделе «ЧТО ПОЛУЧИТСЯ».

LINUX
ExifTool встроен (нужен Perl — на большинстве систем уже есть).
Распакуйте архив, выполните chmod +x TakeoutRestore и запустите ./TakeoutRestore
(откроется браузер через xdg-open, иначе адрес будет в терминале). Пример:
  ./TakeoutRestore -src ~/Takeout -dest ~/Photos-Restored -dry-run -lang ru
Кнопки выбора папки появляются, если установлен zenity или kdialog; иначе путь
можно вставить вручную. Жёсткие ссылки альбомов работают на той же файловой системе.
Полная сборка GUI+CLI для всех платформ: .\build.ps1   или   ./build.sh
Быстро только Windows GUI+CLI: .\build.ps1 -Local
Только CLI+web вручную (Go 1.22+): go build -o TakeoutRestore .

КОМАНДНАЯ СТРОКА (необязательно)
  TakeoutRestore.exe -src "D:\Google Photo Vadzim" -dest "D:\Фото (восстановлено)" -dry-run
  TakeoutRestore.exe -src "D:\Google Photo Vadzim" -dest "D:\Фото (восстановлено)" -lang ru
  Все параметры: TakeoutRestore.exe -h
